# Nexus Builds Landing Page

A responsive landing page for a fictional custom PC building business, built with plain HTML, CSS, and JavaScript.

Live demo: https://emilepieterse.github.io/pc-builder-landing/

## Features

- Prebuilt rig pricing cards
- Interactive build configurator: pick a CPU, GPU, RAM, and storage tier and the total price updates live
- Mobile nav menu with a hamburger toggle
- Nav link highlights the section currently in view while scrolling
- Sections fade in as you scroll to them
- Responsive layout down to phone width

## How to run

No build step or dependencies, just static files.

1. Clone the repo
2. Open `index.html` in a browser

or serve it locally:

```
npx serve .
```

## Tech used

- HTML
- CSS (Grid, Flexbox, media queries)
- Vanilla JavaScript
